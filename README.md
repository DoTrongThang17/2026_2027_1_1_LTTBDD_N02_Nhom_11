## Tính năng chính

- Phát nhạc local (assets): phát / tạm dừng, bài trước / bài sau, mini player
- Thanh sóng âm (waveform) chạm để tua
- Bình luận theo thời điểm trong bài (kiểu SoundCloud)
- Trang chủ, Feed, tìm kiếm bài hát / nghệ sĩ, duyệt theo thể loại
- Thích bài hát, theo dõi nghệ sĩ, trang nghệ sĩ
- Playlist (tạo, đổi tên, xóa, thêm/xóa bài)
- Tải lên bài hát (giả lập)
- Hẹn giờ tắt nhạc (1 / 15 / 30 / 45 / 60 phút)
- Chỉnh âm lượng và tốc độ phát (0.5x - 2x)
- Trang thể loại: nghệ sĩ, sắp xếp Phổ biến / Mới nhất / A-Z
- Bảng xếp hạng: Nghe nhiều / Yêu thích / Bình luận
- Lịch sử tìm kiếm (lưu bằng shared_preferences)
- Giao diện sáng / tối
- Đa ngôn ngữ: Tiếng Việt / English
- Trang thông tin nhóm

## Chạy ứng dụng
